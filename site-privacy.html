プライバシーポリシー（Web サイト・制作のご相談）

このページは、この Web サイトと、制作のご相談の窓口についてのプライバシーポリシーです。Android アプリ「遊技収支ノート」のデータの扱いはアプリのプライバシーポリシー、「小役番長」は小役番長のプライバシーポリシーをご覧ください。

制定日: 2026-11-25 / 運営者: PS Tool Factory（luckys4900、個人で運営） / 連絡先: お問い合わせ

1. 適用範囲

このポリシーは、次の 2 つに適用します。

  • この Web サイト（https://luckys4900.github.io/）を見ていただくとき
  • 制作のご相談の窓口（相談フォーム）からご相談をお送りいただくとき

アプリの中で扱うデータ（収支の記録、広告、購入など）には適用しません。アプリのポリシーをご覧ください。

2. 取得する情報

制作のご相談では、相談フォーム（Google フォーム）で、次の内容をお送りいただきます。

項目必須・任意
お名前必須
会社名・店舗名任意
返信先のメールアドレス必須
ご相談の種類（選択）必須
ご相談内容必須
希望の時期任意
ご予算の目安任意

フォームは、回答者のメールアドレスを自動では集めません。返信先のメールアドレスは、ご自身で入力していただいたものだけを受け取ります。Google へのログインは不要です。

フォームに書く内容は、ご相談に必要な範囲にとどめてください。ご相談に関係のない個人情報は書かないでください。

この Web サイトを見ていただくだけでは、運営者が個人を特定できる情報を集めることはありません。ただし、サイトの配信や外部サービスの読み込みにともなう通信の情報は、次の 4 節のとおり、それぞれのサービスの側で扱われます。

3. 利用目的

相談フォームでお送りいただいた情報は、ご返信と制作のご相談のためだけに使い、ほかの目的には使いません。返信の目安は、数営業日以内です。

4. 外部サービスの利用

このサイトと窓口は、次の外部サービスを使います。それぞれのサービスで、通信の情報（IP アドレス、ブラウザの情報など）が扱われることがあります。取扱いは、各サービスのプライバシーポリシーに従います。

サービス使う場面と、扱われる情報
Google フォーム（Google）制作のご相談の受け付け。お送りいただいた回答は、Google のサービスに保存され、運営者の Google アカウントで管理します。新しい回答があると、運営者にメールで通知されます。
GitHub / GitHub Pagesこの Web サイトの公開。アプリの不具合・質問・プライバシーに関するご請求の窓口（GitHub の Issues）。Issues の内容は公開されます。個人情報や収支の記録は書かないでください。
YouTube（Google）動画の紹介。サムネイル画像は i.ytimg.com から表示します。動画本体は、再生のために押したときだけ youtube-nocookie.com から読み込みます。
Google Fonts（Google）ページを開くと、文字の表示のために、フォントを fonts.googleapis.com と fonts.gstatic.com から読み込みます。
DMM アフィリエイト「関連サービス（PR）」のページのリンクを開いたとき、リンク先で DMM.com が成果の計測を行います（広告とアフィリエイトに関する開示）。

5. アクセス解析

現在、このサイトには Google アナリティクスなどのアクセス解析は導入していません。導入するときは、このポリシーを改定し、使うサービスと取得する情報を書きます。

6. 第三者への提供・委託

お送りいただいた情報は、法令にもとづく場合を除き、ご本人の同意なく第三者に提供しません。ご相談の受け付けと保管には、Google のサービス（Google フォーム）を使います。

7. 保存期間

お送りいただいた回答の保存期間は、定めていません。削除をご希望のときは、8 節の窓口にご連絡ください。

8. 開示・訂正・削除などのご請求

お送りいただいた情報の開示・訂正・削除などは、下記の窓口でお受けします。ご本人であることを確かめるため、フォームで入力された内容をお知らせいただくことがあります。

運営者PS Tool Factory（luckys4900）
窓口お問い合わせの相談フォーム、または GitHub の Issues（GitHub アカウントが必要です。内容は公開されるため、個人情報は書かないでください）
返信の目安数営業日以内

9. 改定

内容を変更するときは、このページを更新し、制定日の下に改定日と変更点を書きます。
