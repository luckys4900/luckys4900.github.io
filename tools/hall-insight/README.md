# 愛媛県ホールインサイト 購読導線（公開前）
- 固定URL: https://luckys4900.github.io/hall-insight/subscribe/
- 既存問い合わせフォームは変更しない。
- Google Forms / Sheets は実行者のGoogleアカウントで作る。回答や編集URLをGitHubに保存しない。

## 初回設定
1. https://script.google.com/ で新しいスタンドアロンプロジェクトを作る。
2. create-form.gs の内容を貼り付け、createHallInsightFormを実行し、Googleの権限確認を行う。実行ログの編集URL・回答URL・回答シートURLを控える。失敗時は既存IDを確認し、重複作成しない。
3. フォーム編集画面から公開し、回答者を「リンクを知っている全員」に設定（組織ポリシーで制限される場合は公開保留）。ログイン不要・回答概要非表示・回答シート非公開を確認。
4. シークレットウィンドウでテスト回答（架空データ）を送り、回答シートに1行入ることを確認。フォームの回答とシートのテスト行を双方削除。
5. hall-insight/subscribe/index.html の FORM_LINK のspanを実際の公開回答URLをhrefにした a.cta（文言「無料レポートを購読する」）に置換。noindexはQR限定運用のため維持。既存レポートページへの案内リンクはフォーム完成後に追加。
6. site-privacy.html に購読利用目的・保存先・停止方法を追記したうえで内容確認。PRをレビュー、公開後に実機でフォームまで再テスト。
7. 公開URLを確認後、固定URLのQRを誤り訂正M以上で生成（白い余白4モジュール以上）。PDF最終ページの右上に追加し、印刷・スマホの双方で読取テスト。
8. 実際の配信は同意済み・停止未申出の登録者だけへ。差出人名、配信停止方法を毎回明記。宛先を他の購読者に公開しない。配布許諾のある資料だけを送信する。

このブランチは準備版。実フォーム作成・公開・登録試験はまだ行っていない。
