このサイトについて

PS Tool Factory は、個人で Android アプリを作っている開発者のサイトです。パチンコ・パチスロを遊ぶ人が、自分の記録を自分で残して見返すための道具を作っています。このサイトでは、アプリの紹介と使い方、記録の付け方や数字の読み方の解説を載せています。

作るときに大切にしていること:

  • 記録と集計に徹する: 遊技・賭け・換金の機能は持たせません。
  • 記録は端末の中に: 利用者の記録を運営者のサーバーに集めません。
  • あおらない: 結果を約束する表現や、遊技を勧める表現を使いません。設定の推測などは「目安」として示します。
  • 18 歳以上が対象: どのアプリも 18 歳以上の方を対象とし、児童向けではありません。

お問い合わせについて

ご質問、不具合のご報告、プライバシーに関するご請求は、お問い合わせのページから GitHub の Issues でお送りください。Issues の内容は公開されるため、個人情報や収支の記録は書かないでください。

このサイトで紹介するアプリは、18歳以上の方を対象としています。遊技はご自身の判断で、のめり込みに注意し、無理のない範囲でお楽しみください。生活に支障が出るときは、相談窓口へ（お住まいの地域の精神保健福祉センターなど）。
